# TEL AVIV: RUN FROM THE INSPECTOR — תל אביב: לברוח מהפקח

משחק תלת־ממדי בדפדפן (Three.js), בסגנון Low-Poly חמים, שרץ גם במחשב וגם בטלפון.

## איך מריצים
- **הכי פשוט:** לפתוח את `index.html` בדפדפן (צריך חיבור לאינטרנט כדי לטעון את Three.js והגופנים).
- **שרת מקומי (מומלץ):** מתוך התיקייה: `python3 -m http.server 8000` ואז לגלוש ל־`http://localhost:8000`.
- בטלפון: לפתוח את אותה כתובת (או קישור ה־Artifact). השליטה עוברת אוטומטית למגע.

## שליטה

## מה יש בגרסה הראשונה
- **עולם:** דיזנגוף (עם שביל אופניים), בן יהודה, שדרות רוטשילד עם קיוסק וכיסאות פלסטיק, פרישמן, גורדון, אלנבי עם דוכני שוק, כיכר עם מזרקה (אזור הולכי רגל), טיילת וחוף עם מטקות. בניינים בסגנון באוהאוס עם דודי שמש, רמזורים עובדים, אבני שפה כחול־לבן / אדום־לבן, שלטים בעברית.
- **עיר חיה:** מכוניות, מוניות ואוטובוס שעוצרים ברמזור וצופרים, שליחים על קורקינטים, הולכי רגל (חלקם עם כלבים, תיירים, חוצים בלי להסתכל), מוכרים בשוק, חבר׳ה בקיוסק — כולם עם משפטים ברקע.
- **רכיבה:** קורקינט חשמלי ואופניים חשמליים, האצה הדרגתית, טורבו עם סוללה, בלימה, הטיה בפניות, התנגשויות ונפילות.
- **5 פקחים עם אישיות:** אבי (עצבני), מוטי (ציני), נועה (חדשה), ששון (ותיק), יוסי (נחמד). כל אחד מסייר באזור משלו.
- **עבירות:** מדרכה, מעבר באדום, בלי לוחית, אזור הולכי רגל, רכיבה מסוכנת. מד חשד מתמלא רק כשהפקח רואה אותך.
- **AI ומרדפים:** זיהוי → קריאה לעצור → מרדף → איבוד קשר עין → חיפוש במקום האחרון → חזרה לסיור. פקחים קוראים לחברים בקשר.
- **ויכוחים:** 4 קטגוריות תשובות (תירוצים / מסכנות ודרמה / ויכוח / התנצלות), שיחות מסתעפות, מדי עצבים ואמון, אפשרות לשלם או לנסות לברוח באמצע.
- **זיכרון:** הפקחים זוכרים מה סיפרת להם (גם בין משחקים) ותופסים סתירות: "רגע, לא פיטרו אותך מוולט?!"
- **תוצאות:** דוח בדיוני מעוצב עם הערות סאטיריות, או אזהרה.
- **התקדמות:** משימות משלוח עם טיימר וטיפ, כסף, ניקוד, הישגים, מוסך שדרוגים (מנוע, סוללה, בלמים, לוחית, אופניים), שמירה אוטומטית בדפדפן.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `js/engine.js` | רנדרר, תאורה, איחוד גיאומטריה סטטית לביצועים, טקסטורות שלטים בעברית |
| `js/text.js` | כל הטקסטים והדיאלוגים (כולל מגדר: `{{זכר|נקבה}}`) |
| `js/world.js` | מפת העיר, משטחים, בניינים, רמזורים, התנגשויות וקו ראייה |
| `js/actors.js` | דמויות, כלי רכב, תנועה, הולכי רגל, ניצבים |
| `js/inspectors.js` | בינה מלאכותית של הפקחים |
| `js/dialogue.js` | מנוע הוויכוחים, זיכרון, דוחות |
| `js/game.js` | שחקן, שליטה, מצלמה, ממשק, משימות, מוסך, שמירה, לולאת משחק |

להוספת תירוצים חדשים: מוסיפים אובייקט למערך `OPTS` ב־`js/text.js`.

## הצעות להמשך
עוד רחובות (שוק הכרמל המלא, נווה צדק), משימות מרדף ומכשולים, פקחים נוספים, התאמה אישית של הדמות, מוזיקה, ודיבוב.

> העבירות הן חלק ממערכת המשחק בלבד ואינן המלצה להתנהגות במציאות.
